# Screenshots

## Purpose

This document defines the approved location and handling rules for Version 2 repository screenshots.

Repository screenshots belong in `docs/screenshots/`.

Add reviewed, current captures there using descriptive filenames, and reference them from the README when they represent the current Version 2 release. Do not commit screenshots containing credentials, tokens, private student data, or other sensitive information.

This documentation phase does not generate or modify screenshots.
