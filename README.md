# 📖 Overview

Enterprise College ERP V9 Lite is a modern AI-enabled College Enterprise Resource Planning (ERP) System developed as a BCA Major Project.

The system provides a secure and scalable platform for managing academic, administrative, and AI-powered services within an educational institution.

---

# ✨ Current Features

### 🔐 Authentication

- Secure Login
- JWT Authentication
- Password Encryption
- Role Based Access Control (RBAC)

### 👥 User Management

- Super Admin
- Admin
- Faculty
- Student

### 🎓 Academic Management

- Student Management
- Faculty Management
- Department Management
- Course Management
- Semester Management

### 📚 ERP Modules

- Attendance
- Examination
- Library
- Fee Management
- Notice Board

### 🤖 AI

- AI Assistant
- AI Admin Panel
- AI Foundation
- AI search, prompt library, document index, and usage-ready platform APIs

### 🧭 Enterprise Integration

- Unified global search with `Ctrl/Cmd + K`
- Centralized notification center
- Report Center
- Role-aware dashboards and navigation
- Student, faculty, academic, examination, finance, library, attendance, assignment, and notice workflows
- Development-only demo role switching
